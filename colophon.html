About This Website (Colophon)

This website was developed as part of Assignment 1 for the WEB Technologies 1 (Front End) course. The project represents a real physical travel agency — HT.KZ.

Technologies & Standards

The site is built strictly using pure HTML5 without any external CSS styling or JavaScript scripts.
All pages follow semantic layout principles, using tags like <header>, <nav>, <main>, <article>, and <footer>.

Validation status: Verified via W3C Markup Validation Service.

Status output: Document checking completed. No errors or warnings to show.
