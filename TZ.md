## 0. Правила, действующие на КАЖДОЙ из 8 страниц

- `<!DOCTYPE html>`, `lang="en"`, `charset`, `viewport`, `<meta name="description">`, `<meta name="author" content="Имя">`, уникальный `<title>`.
- Ровно один `<h1>`, без пропуска уровней заголовков.
- Скелет: `<header>` → `<nav>` со ссылками на все 8 страниц → `<main>` → `<footer>` (контакты, `&copy;`).
- HTML-комментарий с именем автора + минимум 2 комментария «почему» (не «что»).
- Никакого `style=`, `<style>`, ссылок на CSS, `<script>` на этом этапе.
- как минимум один `div` и `span` — только там, где реально не подходит ни один семантический тег, и рядом обязательно комментарий, почему. Каждый "неправильный" div стоит 5 штрафных баллов.
- Никакого Lorem ipsum, никаких стоковых или AI-сгенерированных изображений, никаких выдуманных цифр — всё должно опираться на реальные данные аккаунта ayana.buyer (347 постов, 5 997 подписчиков, страны: США/Корея/Турция/Италия/Германия, Kaspi рассрочка, WhatsApp-чат совместных закупок) или на реально собранную информацию (интервью, фото, цитаты).

## 2. Требования по каждому файлу

### index.html — автор A
**Контент (150–250 слов):** кто такие ayana.buyer, чем занимаются (доставка мировых брендов, Kaspi рассрочка, совместные закупки через WhatsApp-чат), для кого сайт, призыв перейти в "Популярные магазины".

**Обязательные элементы:**
- `section` — "Как это работает" (3 шага: выбрать товар → оформить заказ → получить с рассрочкой Kaspi).
- `article` — короткая новость/анонс.
- `figure`+`figcaption` — 1-е из 3 изображений сайта.
- Вложенный список — "Категории товаров": одежда → (обувь, аксессуары), техника → (гаджеты, посуда).
- `strong`/`em` для акцентов.
- Минимум 1 HTML-сущность (из 4 нужных по сайту).
- Комментарий автора + 2 комментария "почему".

### stores.html — автор A
**Контент:** обзорный хаб — какие магазины в целом привозит сервис, история, география (5 стран).

**Обязательные элементы:**
- **Таблица** с `caption`/`thead`/`tbody`/`th scope="col"` — "Магазин | Категория | Ориентировочный срок доставки".
- `dl`/`dt`/`dd` — термины: "Байер", "Kaspi рассрочка", "Совместная закупка".
- `blockquote`+`cite` — настоящая собранная цитата.
- 2 × `abbr title="…"` — например США, Корея.
- `aside` — врезка-факт ("Вы знали что у нас есть Instagram? Там вы можете заказать через директ или посмотреть отзывы").
- `small` — приписка/дисклеймер под цифрами.

### reviews.html — автор A
**Контент:** отзывы реальных клиентов + контакты (Instagram, WhatsApp, телефон, часы работы) — сюда переехали функции старых about_us/contacts.

**Обязательные элементы:**
- Внешняя ссылка `target="_blank" rel="noopener"` — Instagram/WhatsApp.
- `mailto:` ссылка.
- `tel:` ссылка — реальный формат номера.
- 2 ссылки-якоря на `id` внутри страницы (например, мини-навигация "Отзывы" / "Как связаться").
- `figure`+`figcaption` — 2-е из 3 изображений сайта (например, фото визитки/пункта выдачи).
- `ol start="…"` или `type="I"` — "Порядок оформления заказа".
- `q` — короткая инлайн-цитата от команды поддержки.
- **Комментарий**: если форма всё же физически будет одна на весь сайт (см. п. 0.1), логичное место для неё — здесь, рядом с контактами.

### shoes.html / clothing.html / accessories.html — автор B
**Контент:** для каждой — список популярных магазинов этой категории с описанием (в духе a2zbuyer: Adidas, New Balance, Vans и т.д.), реальные позиции из каталога ayana.buyer.
**Контент shoes.html:** реальные модели из каталога — Nike (Air Max, Dunk, Terminator, V2K Run), Air Jordan/Jordan, Adidas (Samba, Response, Ozelia), New Balance, Puma (Speedcat), UGG, Guess (ботинки), Tommy Hilfiger (Suede Mix Tonal), Nursace (турецкий бренд — реальная деталь географии поставок, можно связать с Турцией из общей темы сайта).
**Контент clothing.html:** Tommy Hilfiger (куртки), Calvin Klein, Lacoste, Zara, Massimo Dutti, Guess.
**Контент accessories:** Michael Kors (сумки, рюкзаки, часы "Runway"), Tissot (часы), Guess (сумочки, барсетки), Tommy Hilfiger (кепки), Gucci (палантин/шарф), Victoria's Secret (косметичка), Stanley (термокружка).

**Обязательные элементы (распределить между тремя страницами, не дублировать без надобности):**
- **Таблица** с `caption`/`thead`/`tbody`/`th scope` — "Товар | Бренд | Цена | Наличие" (на одной из трёх).
- `ol start="1"` или `reversed` — "Топ-5 популярных позиций" (на другой).
- 3-е из обязательных изображений сайта — фото товара с осмысленным `alt`.
- `mark` — "Скидка"/"Последний размер".
- `sup`/`sub` — сноска у цены.
- Вложенный список — "Категории аксессуаров": сумки → (Jw Pei, Coach), часы → (мужские, женские) — на accessories.html.
- `strong` — бренд, `em` — статус наличия.
- **Форма заказа** — внизу каждой из трёх страниц: `method`, `action`, `fieldset`+`legend`, `label`+`id`, `text`(получатель),`url`(ссылка на товар) `tel`, `number`(количество), `date`(дата доставки), `radio`(способ оплаты), `checkbox`(согласие), `select`(способ доставки), `textarea`(необязательное примечание), `required`/`placeholder`, `submit`+`reset`, комментарий "сервера пока нет". Комментарий в коде: "форма идентична на всех товарных страницах — единая форма команды по разрешению преподавателя".

### sportswear.html / electronics.html — автор C
**Контент:** аналогично B — популярные магазины по технике (Apple, Sony, JBL) и посуде.
**Контент sportswear.html:** Nike, Adidas, Puma, New Balance, Jordan — **но не повтор обувных моделей с shoes.html**, а разрез "бренд как экосистема": что бренд предлагает в одежде/аксессуарах, известные коллаборации, почему эти 5 брендов выделены в отдельную категорию у ayana.buyer (спортивный стиль как отдельный спрос клиентов).
**Контент electronics.html:** Dyson (фены-стайлеры Airwrap), Apple (iPhone). Немного брендов — это нормально, компенсируйте объёмом реального описания (сроки доставки из США/откуда конкретно везёте, гарантия, растаможка).

**Обязательные элементы:**
- `blockquote`+`cite` — реальный отзыв о заказе техники/посуды (если не набралось у A).
- `dl` — термины при заказе ("Оригинал", "Гарантия", "Трек-номер") — если ещё не закрыт список.
- `hr` — разделитель между списком товаров и формой.
- `br` — там, где уместно разбить строку адреса.
- Ещё 2 × `abbr title="…"`, если не набралось у A.
- Та же **форма заказа**, что и на B-страницах — внизу каждой из двух страниц, с тем же комментарием про единую форму.
